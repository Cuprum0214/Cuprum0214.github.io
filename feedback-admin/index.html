数据库结构

管理端的「回复 / 已读 / 删除」需要所有者表结构。
请在 Supabase SQL Editor 运行仓库里的 supabase/schema.sql（幂等，可重复执行）。

它会在 feedback 上启用 RLS 所有者策略，并创建 owner_emails、 feedback_replies、is_owner()。

可读但无法管理，说明当前项目只跑了 supabase/public-read.sql（公开只读模式）。
